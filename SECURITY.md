# Security Policy — Advanced Boss Mods (BigWigs) 🔒⚔️

Protegemos la integridad de tu operativa de raideo en **Turtle WoW**.

## 🛡️ Soporte por Versión
| Versión | Estado |
| --- | --- |
| v9.4.0 | ✅ Soportada |
| v9.3.x | ⚠️ Crítico |

## 🛡️ Reporte de Vulnerabilidades
Si descubres un bug que compromise la estabilidad del cliente de WoW durante un encuentro de banda o que cause caídas de FPS que afecten al grupo entero:

1.  **NO publique el exploit masivamente.**
2.  Reporta vía **Discord oficial** de **DarckRovert**.
3.  Incluye el log de `BigWigs -> Plugins\Comm.lua`.

## 🛡️ Protecciones Integradas
- **Communication Throttling**: El motor de red (Comm) fragmenta los avisos de banda para no saturar el canal `SAY` o `RAID` del cliente.
- **Selective Memory Cleanup**: BigWigs purga de memoria automáticamente los módulos de raids en los que el jugador no se encuentra actualmente.
